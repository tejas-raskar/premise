# Engineering memory

Premise records the reasons for engineering decisions and the evidence that supports them.

## Language

**Decision**: A recommendation with an explicit scope and reason.

**Assumption**: A claim on which a decision depends.

**Support set**: A group of assumptions that must all hold to support a decision.
One valid support set is sufficient when a decision has several support sets.

**Contract**: An expected behavior of an API or other code interface.

**Evidence**: An observation tied to a source and a specific revision.

**Assessment**: The result of an evaluation of a decision at a specific revision.

**Revalidation**: A new check of evidence after a relevant change.

**Supersession**: The replacement of a decision within an explicit scope.
The previous decision remains part of the history.
